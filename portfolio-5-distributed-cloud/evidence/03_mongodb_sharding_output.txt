2. SHARD KEY SELECTION & TRADEOFF EVALUATION
======================================================================
EkoMart Evaluated Three Candidate Shard Keys for the 'orders' collection:

A. Single Field Hashed: { order_id: 'hashed' }
   - Advantage: Perfectly uniform write distribution; zero hotspots.
   - Drawback: Cross-partition scatter-gather on regional dispatch queries.

B. Monotonically Increasing: { order_date: 1 }
   - CRITICAL FLAW: All new inserts hit a single shard (write hotspot bottleneck).

C. Compound Co-located Key (SELECTED): { 'delivery.region_id': 1, 'order_id': 'hashed' }
   - Advantage: Combines targeted regional routing with hashed balance inside each zone!

  sh.addShardTag('shard_nc_abuja', 'ZONE_NORTH_CENTRAL');
  sh.addShardTag('shard_eastern_ph', 'ZONE_EASTERN');
